## 2025-05-15 - [Dynamic Drawer Accessibility & Flow]
**Learning:** In JS-driven UI components like slide-out drawers or mobile menus, simply toggling a visibility class is insufficient for accessibility. The trigger elements must dynamically synchronize their `aria-expanded` state and `aria-label` (e.g., "Open bag" vs "Close bag") to provide immediate feedback to assistive technologies. Additionally, "Empty States" should be treated as navigation opportunities; adding a "Shop Now" CTA that closes the drawer upon click prevents UX "dead-ends" and maintains user momentum.
**Action:** Always implement a state-syncing function for interactive panels that updates ARIA attributes on both the trigger and the panel, and ensure empty states include a primary action linked to the site's main conversion path.
